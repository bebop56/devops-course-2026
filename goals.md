# Мои цели на семестр

## 1. Освоить Docker и контейнеризацию
Хочу научиться упаковывать приложения в контейнеры, писать эффективные Dockerfile и управлять многоконтейнерными приложениями через Docker Compose. К концу семестра планирую собрать и запустить собственный пет-проект в контейнере.

## 2. Настроить CI/CD пайплайн на GitHub Actions
Цель — автоматизировать сборку, тестирование и деплой своего проекта. Хочу разобраться, как работают воркфлоу, секреты и матричные сборки, чтобы каждый пуш в репозиторий автоматически проверялся и выкладывался на сервер.

## 3. Подтянуть Linux и Bash
Научиться уверенно работать в терминале: писать простые скрипты автоматизации, управлять процессами, правами доступа и пользователями. Это база для работы с серверами и CI/CD.
