# Мой пет-проект

**Идея:** Телеграм-бот для учёта личных расходов. Бот позволяет быстро записывать траты прямо из чата, а раз в неделю присылает красивую статистику в виде диаграммы.

**Стек:** Python (aiogram), SQLite, Matplotlib (для графиков)

**Цель:** научиться работать с асинхронным Python, освоить библиотеку aiogram для создания ботов и попрактиковаться в проектировании баз данных.
